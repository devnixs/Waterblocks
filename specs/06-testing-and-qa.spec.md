- [X] TEST-013: Regression test for the `addresses_paginated` infinite-loop bug (VAULT-009). Seeds a BTC wallet whose primary "Permanent" address has a NULL `Bip44AddressIndex` plus enough deposit addresses that the total is an exact multiple of the page size (99 deposits + 1 permanent = 100 = 2 × 50) — the precise condition under which the old BIP44-index cursor would not advance. Walks the endpoint exactly like the production client (`count=50`, following the `after` cursor) under a hard iteration cap, then asserts the walk terminated via an empty cursor (not the cap), returned every address exactly once with no duplicates, and surfaced the permanent address a single time. Fails against the pre-fix cursor logic and passes against the offset-based implementation. Source: `tests/backend/integration/VaultAddressPaginationTests.cs`. Confidence: high.
