Let's introduce the concept of "MemoBased" assets.

For these assets, when an address is generated, it is associated with a memo.

Example: When we create a new BTC wallet of the same vault, it generates a new address. This is how address based blockchain work

For ETH, we cannot have two different addresses for the same vault. This is how AccountBased blockchain work.

For MemoBased blockchains, we can generate multiple wallets, but this will just generate a new memo.
